# Sistema Bancário em Java

Projeto desenvolvido para praticar Programação Orientada a Objetos (POO) em Java.
O sistema simula operações básicas de um banco utilizando classes, associação entre objetos e listas dinâmicas.

## Funcionalidades

* Criar conta bancária
* Associar conta a um cliente
* Depositar dinheiro
* Sacar dinheiro
* Listar contas cadastradas

## Conceitos praticados

* Programação Orientada a Objetos
* Classes e objetos
* Encapsulamento
* Associação entre classes
* Uso de ArrayList
* Estrutura de menu com Scanner
* Organização em pacotes

## Tecnologias utilizadas

* Java
* IntelliJ IDEA
* Git
* GitHub
