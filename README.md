# Sistema Bancário em Java

Projeto desenvolvido para praticar Programação Orientada a Objetos (POO) em Java, simulando um sistema bancário com cadastro de contas e operações de depósito, saque e consulta de saldo.

## Funcionalidades

- Cadastrar conta bancária
- Impedir o cadastro de contas com número duplicado
- Validar número da conta e saldo inicial
- Depositar dinheiro
- Sacar dinheiro
- Impedir depósitos e saques com valores inválidos
- Impedir saques quando o saldo é insuficiente
- Consultar saldo de uma conta
- Listar contas cadastradas
- Contar a quantidade de contas criadas
